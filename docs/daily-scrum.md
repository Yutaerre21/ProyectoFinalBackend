# Daily Scrum — instrucciones de registro

No se han realizado dailies durante esta sesión. El taller exige al menos tres por semana, grabadas en Microsoft Teams.

En cada registro real se debe indicar:

1. Fecha y asistentes.
2. Avance desde la reunión anterior con enlaces a Issues/PRs concretos.
3. Trabajo siguiente y responsable.
4. Bloqueos, acción para resolverlos y fecha objetivo.
5. Enlace a grabación y permisos de acceso.

Organizar los registros bajo Sprint 1, 2 y 3 cuando ocurran. No backdatear reuniones ni afirmar asistencia sin evidencia.
